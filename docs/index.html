AI TRPG / Co-op Roleplay

2人とAIが同じ物語を紡ぐ、即興ロールプレイゲーム。

プレイヤーの発言、AIナレーター、NPCの反応、キャラクターカード、 ステータス、ワールド状況をひとつのセッションで管理します。 日本語UIと日本語ナレーションに対応しています。

画面を見る GitHub

Features

ゲーム内の主要機能

01

日本語ナレーション

ルーム作成時の言語設定をAIに伝え、ナレーターとNPCの本文を日本語で生成します。

02

キャラクター選択

アカウントキャラ、デフォルト入室、AI生成キャラを選べます。

03

ステータス管理

職業、ランク、能力値、所持金、状態、インベントリをセッション中に確認できます。

04

ワールド状況

現在地、時間、NPC配置、裏側の動き、エンディングリスクをパネルで把握できます。

05

移動と探索

プレイヤーはシーンを移動し、AIが新しい状況をナレーションします。

06

シーン画像生成

現在の場面や指定したアクションをもとに、シーン画像生成の設定を行えます。

NPC System

実際のゲーム画面で見るNPC内心・返信・シーン記録

NPCの思考ログ、返信、プレイヤー/NPCアバター、シーン記録はゲームUI上でそのまま確認できます。
